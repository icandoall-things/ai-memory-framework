02

三层记忆：各自装什么

判定标准只有一句话 —— 换个系统还成立吗？

通用 MEMORY

D:\AI-MEMORY\通用MEMORY\
判定：换到另一个系统，这条还成立吗？
  • 怎么跟你沟通 大白话＋类比
  • 记忆的写法 只写长期约束，不写"此刻状态"
  • 技能库位置 D:\claude-skills\
  • 工具装 D:\<名字>，别进项目文件夹
  • API key 不写进任何文档
  • 报告要保留原始图表

Windows MEMORY

D:\AI-MEMORY\WindowsMEMORY\
判定：只在 Windows 上做的事
  • 众盈杯（目标检测比赛）
  • 明纬杯（开关电源 / PCB）
  • 课程作业 · 实验报告
  • Windows 系统·驱动·外设排查
  • PowerShell / 盘符路径规矩
  • 众盈杯等项目的 当前进度（会过期）

Ubuntu MEMORY

D:\AI-MEMORY\UbuntuMEMORY\
判定：只在 Ubuntu 上做的事
  • ROS2 Humble / 工作区
  • 内置键盘 kbd_poll 轮询驱动
  • 无线键盘断电重连方案
  • Ubuntu 装机 / 分区 / apt 源
  • npm·node 环境（v22）
  • Ubuntu 侧当前状态（会过期）
03

文件放哪 · 两边怎么接上

全放 D 盘：NTFS 两个系统都读写得到 
D:\AI-MEMORY\
├── 通用MEMORY\
│   ├── MEMORY.md          ← 索引 + 路由表（第一入口）
│   ├── 沟通风格.md
│   ├── 记忆规矩.md
│   └── 技能库位置.md
├── WindowsMEMORY\
│   ├── MEMORY.md          ← 索引
│   ├── 众盈杯\ …
│   ├── 明纬杯\ …
│   ├── 课程作业\ …
│   └── 本机Windows\ …
└── UbuntuMEMORY\
    ├── MEMORY.md          ← 索引
    ├── ROS2\ …
    ├── 本机Linux\ …
    └── 远程与网络\ …
Windows 侧
C:\Users\35098\.claude\CLAUDE.md   @D:\AI-MEMORY\通用MEMORY\MEMORY.md   @D:\AI-MEMORY\WindowsMEMORY\MEMORY.md
Ubuntu 侧
/home/yyy/.claude/CLAUDE.md   @/media/yyy/Windows盘/AI-MEMORY/通用MEMORY/MEMORY.md   @/media/yyy/Windows盘/AI-MEMORY/UbuntuMEMORY/MEMORY.md
要点：`@` 那一行就是"只读自己那两份"。D 盘没挂载时 Ubuntu 那两行会静默失效（不报错）—— 所以启动前点一下 D 盘，或者放进开机自动挂载。
