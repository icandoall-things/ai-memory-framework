# 通用记忆 · 索引与路由（第一入口）

> 本文件在**两个系统**上都会被自动加载（各自 `CLAUDE.md` 里的 `@引入`）。
> 它是三级记忆架构的入口。看完这里，再按「任务载体」决定读哪个系统层。

---

## 一、三级架构

```
<共享盘>\AI-MEMORY\
├── 通用MEMORY\      ← 换个系统还成立的规矩          ← 你在这里
├── <系统A>MEMORY\   ← 只在 <系统 A> 上做的事
└── <系统B>MEMORY\   ← 只在 <系统 B> 上做的事
```

| 层 | 自动加载于 | 装什么 |
|---|---|---|
| 通用 | 两边都加载 | 沟通风格、记忆规矩、技能库位置、双系统约定 |
| <系统A> | 只有 <系统 A> | <按实际项目/域填写> |
| <系统B> | 只有 <系统 B> | <按实际项目/域填写> |

**分层判定标准只有一句。换到另一个系统，这条还成立吗。** 成立 → 通用层。

---

## 二、接任务先路由

```
你下达任务
   │
   ▼
① 判断「任务载体」 ──┬── <系统A> 专属 ──▶ 读 通用 ＋ <系统A>MEMORY
                     ├── <系统B> 专属 ──▶ 读 通用 ＋ <系统B>MEMORY
                     ├── 跨系统       ──▶ 三层全读
                     └── 纯通用       ──▶ 只读 通用
   │
   ▼
② 先说一句再干，例如「这是 <系统A> 任务，我读了通用＋<系统A>」
   │
   ▼
③ 判断该调哪个 skill（扫技能列表 → 说出调哪个、为什么）
   │
   ▼
④ 执行 → 有新规矩就写回对应那层，并在该层 MEMORY.md 加一行
```

**跨系统的典型任务** 有共享盘上的工具链、技能库、双系统时间，还有这套记忆本身的维护。

> ⚠️ **分层只决定「默认自动加载哪几层」，不是访问权限墙。**
> 三层文件都在共享盘上，**两边都读得到**。任务做到一半发现需要另一层的知识，
> **随时跨层去读**，说一声即可。**规则别写死。**

## 四、索引纪律

- 本文件是**通用层**的索引。新增一条通用记忆 → 在「本层条目」里加一行。
- 会过期的状态（「装到哪一步了」）**不要**放通用层，放对应系统层。
- 每层都有自己的 `MEMORY.md`；跨层引用用相对路径 `..\<系统>MEMORY\xxx.md`。
- 一条记忆一个文件，不要把几条独立约束塞进同一个文件。
